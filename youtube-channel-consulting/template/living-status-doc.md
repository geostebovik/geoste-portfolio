# Living Status Doc Template (paste into Project Knowledge, edit in place)

```
# [Client/Channel Name] — YouTube Project Status

Last updated: [date]

## Current state
[Where things stand right now — channel metrics, what's live, what's
paused, what's mid-change. Update this section every session; don't leave
last session's snapshot stale.]

## Decisions made (and why)
- [Decision] — [the reasoning/data point behind it, not just the choice.
  If it's a cheap-to-reverse call made without full certainty, say so
  explicitly: "decided now on best available reasoning, revisable."]

## Open questions
- [Anything unresolved — data still needed, client input pending, a
  hypothesis not yet tested]

## Next action
- [The single next concrete step — not a backlog, just what happens next]
```

**Rule for this file, in every client folder:** edit in place, every
session. Never fork into a dated copy. If the structure above stops
fitting a client's needs, change the structure — don't start a second
file next to it.
